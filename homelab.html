Proxmox · WireGuard · Traefik + Authentik · VLAN segmentation

Homelab Services Architecture

A dedicated Proxmox host for everyday self-hosted services (media, game servers, and my own ops dashboard) plus Dot AI, a local voice assistant I designed with the assistance of Cursor that runs on its own GPU PC. Each workload lives on its own VLAN behind the lab gateway, every web UI is reached through one Traefik entry point with Authentik SSO, and remote access is WireGuard only.

Proxmox VE VLANs 3 · 8 · 70 · 71 · 73 · 75 Traefik + Authentik SSO 1 TB media pool (VirtioFS) Remote access: WireGuard only

Segmented services

Core, media, gaming, and the AI box each get a VLAN and a default-deny firewall policy.

Single, authenticated front door

AdGuard DNS → Traefik → Authentik for every UI. WireGuard peers land on their own VLAN.

Ops dashboard + Dot AI

Lab Dash monitors and controls both Proxmox hosts. Dot, a fully local voice assistant, is always listening on it and speaks alerts.

Dot AI — local voice assistant

VLAN 3 · dedicated GPU PC

Dot is a JARVIS-style personal assistant I designed for this lab with the assistance of Cursor. I directed the architecture, integrations, and behavior; Cursor helped write and iterate on the implementation. It runs on a dedicated PC (see hardware) and every model is local: Faster-Whisper on the GPU for speech-to-text, an 8B Llama model on Ollama for conversation, and a cloned voice from XTTS with Piper as fallback. No voice or lab data leaves the house. It is served over HTTPS behind Authentik.

Voice

Browser open mic

  • Wake on “Dot”, “Hey Dot”, “Hello Dot”…
  • Silero / energy VAD in the browser, Whisper wake gate
  • 60 s conversation window, no repeat wake word
  • Push-to-talk and text chat

Conversation

Local Llama model

  • Skills first; LLM pulls location, day, query from context
  • Streaming replies
  • Session memory that survives reconnects
  • Remembers preferences and facts across sessions

Everyday skills

Assistant

  • Weather (Open-Meteo) and news (RSS)
  • Web lookup (DuckDuckGo + Wikipedia)
  • Nearby places (OpenStreetMap)
  • Timers, reminders, weekly chores

Homelab skills

Read-only via ops API

  • “What's down?” service health

Camera security

  • Names authorized people it recognizes
  • Flags unauthorized people

Spoken alerts

Push into Dot

  • Wazuh alerts rated “high” or above
  • Frigate person events
  • Played on every open console / Lab Dash

How Dot is wired to the rest of the lab

Embed: the dashboard only loads Dot for signed-in users, and Dot only allows itself to be embedded by the ops dashboard. HTTPS is required for the browser microphone. Push in: the ops dashboard and the camera forwarder send alerts to Dot over an authenticated webhook, while people sign in through Authentik. Read out: Dot calls a read-only ops API with its own credential for status, alerts, VMs, IoT, cameras, and the calendar, and can create calendar events. It has no start, stop, or restart actions.

Operational flows

How day-to-day use works

1 Remote access (WireGuard)

Phone / laptop→ Home edge gateway→ Lab gateway forward→ WireGuard LXC (VLAN 70)→ Peer IP on VLAN 75→ AdGuard → Traefik → Authentik

Split tunnel to lab subnets with AdGuard as DNS, so lab hostnames work anywhere.

2 Opening any web app

Browser→ AdGuard: lab hostname → Traefik→ Traefik (TLS)→ Authentik forward-auth / OIDC→ App on its own VLAN

Jellyfin keeps its own user accounts for TV clients; Immich signs in through Authentik OIDC.

3 Friends join a game server

Friend's PC→ WireGuard peer→ Lab gateway allow→ Game server (VLAN 73)

The dashboard's Gaming tab shows who is online and can switch or back up worlds without SSH.

4 Talking to Dot

Lab Dash mic (browser)→ “Dot …” wake: VAD + Whisper→ Skill or local LLM→ Read-only ops API (lab data)→ XTTS voice reply

After the first “Dot”, follow-ups don't need the wake word until 60 seconds of silence.

5 Security alerts → voice

Wazuh manager (SOC VLAN 2)→ Ops dashboard webhook + ntfy→ Dot speaks “high” alerts
Frigate person event (SOC host, VLAN 74)→ MQTT forwarder on the AI box→ Dot announces known person or stranger

Clicking a Wazuh alert opens the exact Discover document. Camera pipeline details are on the SOC page.
