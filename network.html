How it fits together

One fabric, separate trust zones

Everything on this page is built and running. The home internet edge and the lab are deliberately separate: the home edge gateway serves personal devices, and a downstream lab gateway owns every lab network, its DHCP, inter-VLAN routing, and the zone firewall. Each workload gets its own VLAN, traffic between VLANs is denied unless a rule allows it, and the only way in from the internet is WireGuard. The pages for the cybersecurity lab and homelab services cover what runs on each network; this page covers the network and hardware underneath them.

Physical network topology

As built

The ISP fiber gateway passes the public IP to the home edge gateway, which runs the home LAN for personal devices. The lab gateway takes a WAN address on that LAN and is the gateway for every lab, homelab, and AI VLAN. Inter-VLAN routing and firewalling stay on the lab gateway, so the home edge gateway only handles north–south traffic.

Home edge

Home edge gateway

Takes the ISP public IP via passthrough and serves the home LAN for personal devices. Forwards WireGuard to the lab gateway and otherwise does not see lab east–west traffic.

Lab gateway

Lab gateway

Gateway for all 12 VLANs: DHCP, inter-VLAN routing, and the zone-based firewall policy table. VLAN trunks go to both Proxmox hosts through the lab switch.

Hardware

What runs it all

Three machines do the compute, each sized for its job. The InfoSec host has the most memory because the SIEM, Elasticsearch, and the analysis VMs are the heaviest workloads. The services host runs lighter containers but holds the media pool. AI inference runs on its own PC so voice and language models never compete with the SOC for GPU or RAM.

Trust zones & cross-domain links

Lab gateway zone firewall

Every VLAN-to-VLAN path is denied by default. The table below lists the only paths allowed between the three areas; detailed rule sets for each area are on the cybersecurity and homelab pages.

Inbound from the internet

WireGuard is the only way in

The home edge gateway forwards WireGuard to the lab gateway, which forwards it to the WireGuard LXC on VLAN 70. No service, camera, or game server has a public port-forward; friends and my phone come in over the VPN.

Outbound to the internet

Decided per VLAN

The malware sandbox and cameras have no internet route at all. SOC services get only DNS and web access for feed and image updates, and every other VLAN is limited to what its services need.
